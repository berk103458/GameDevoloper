# Meshy Discover'dan indirilecek hazır asetler

Meshy'nin ücretsiz topluluk modelleri (Discover) API ile değil, **tarayıcıda hesaba girerek** iner.
İndirdiğiniz `.glb` dosyalarını bu klasöre koyup push edin (GitHub Desktop: Commit → Push).
Claude her dosyayı açıp bakar; oyuna uymayanları (modern, fantastik, parlak çizgi film, metal zırh)
ayıklar, boyunu ve yönünü düzeltir, `assets/model/` altına adını koyup oyuna bağlar.

**İndirme:** meshy.ai → Discover → arama → modeli aç → Download → **GLB**.
Dosya adını değiştirmeniz gerekmez; isterseniz aşağıdaki adı verin.

## Öncelik 1 — köyü canlandıracaklar
| Ad | Discover'da arama | Not |
|---|---|---|
| tavuk | `chicken`, `hen` | gerçekçi ya da low-poly, çizgi film değil |
| kopek | `dog`, `shepherd dog` | çoban köpeği gibi |
| keci | `goat` | |
| inek / okuz | `cow`, `ox` | kağnıya koşulabilir |
| at | `horse` | eğersiz ya da basit eğerli |
| esek | `donkey` | |
